# 日本酒类税法（清酒）

**Japan Liquor Tax Law**

## 概述

日本《酒税法》规定清酒分级、税率、生产工艺与标签要求，是日本酒类的核心法规。

## 法律背景

**《酒税法》（酒税法，昭和28年法律第6号）** 是日本管理酒类生产、销售与征税的核心法律，由国税厅（NTA）执行。

### 酒类分类

依据《酒税法》第3条，酒类分为10类：

| 类别 | 定义 | 示例 |
|------|------|------|
| 清酒 | 米、米麹、水发酵，过滤 | 日本酒 |
| 合成清酒 | 添加酒精、糖等 | - |
| 焼酎 | 蒸馏酒（甲类/乙类） | 烧酎 |
| みりん | 米、米麹加烧酎 | 味醂 |
| ビール | 麦芽、水发酵 | 啤酒 |
| 果実酒 | 水果发酵 | 葡萄酒 |
| 発泡酒 | 不符合啤酒定义的发泡酒 | 发泡酒 |
| 雑酒 | 其他酒类 | 利口酒、威士忌等 |
| スピリッツ | 蒸馏烈酒 | 伏特加、朗姆 |
| リキュール | 浸渍/调和酒 | 利口酒 |

### 清酒分级（特定名称酒）

依据《清酒の製法品質表示基準》（国税庁告示第8号）：

| 名称 | 精米歩合 | 麹米使用率 | 添加酒精 |
|------|----------|------------|----------|
| 吟醸 | ≤60% | ≥15% | 允许（≤120kg/1t白米） |
| 大吟醸 | ≤50% | ≥15% | 允许（≤120kg/1t白米） |
| 純米 | 无限制 | ≥15% | 禁止 |
| 純米吟醸 | ≤60% | ≥15% | 禁止 |
| 純米大吟醸 | ≤50% | ≥15% | 禁止 |
| 特別純米 | ≤60%或特别工艺 | ≥15% | 禁止 |
| 本醸造 | ≤70% | ≥15% | 允许（≤120kg/1t白米） |
| 特別本醸造 | ≤60%或特别工艺 | ≥15% | 允许（≤120kg/1t白米） |

**注**：特定名称酒以外的清酒称为"普通酒"，占日本清酒总产量约70%。

### 酒税率（2023年修订）

| 酒类 | ABV | 税率（每1L） |
|------|------|-------------|
| 清酒 | 16%以上 | 122.0日元 |
| 清酒 | 15-16% | 110.0日元 |
| 烧酎（甲类） | 21%以上 | 220.0日元 |
| 烧酎（乙类） | 21%以上 | 220.0日元 |
| 啤酒 | - | 200.0日元（2026年降至187.0） |
| 发泡酒 | - | 134.4日元 |
| 葡萄酒 | - | 80.0日元 |
| 威士忌 | - | 282.0日元 |

### 标签要求

- **制造年月**：瓶装日期
- **原材料名**：米、米麹、酿造酒精
- **精米歩合**：特定名称酒须标注
- **酒精度**：±1.0%
- **内容量**：公制
