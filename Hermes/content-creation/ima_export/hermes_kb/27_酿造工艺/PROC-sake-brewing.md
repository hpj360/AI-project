# 清酒酿造工艺（清酒）

**Sake Brewing Process**

## 概述

清酒酿造是世界独特工艺，并行复发酵同时进行糖化与发酵，造就复杂精致风味。

## 清酒酿造概述

### 核心特点
- **原料**：米、水、麹（koji）、酵母
- **独特工艺**：并行复发酵 Multiple Parallel Fermentation
- **酒精度**：18-20%（装瓶时稀释至15-16%）
- **发酵微生物**：麹菌 + 酵母

### 与啤酒的差异
- 啤酒：先糖化后发酵（顺序）
- 清酒：糖化与发酵同时进行（并行）
- 原因：温度调节，避免糖分过高抑制酵母

## 酿造流程

### 1. 原料准备

#### 精米 Polishing
- **精米步合 Seimaibuai**：剩余比例
  - 70%以下：本酿造、纯米
  - 60%以下：特别本酿造、纯米吟酿
  - 50%以下：吟酿
  - 40%以下：大吟酿
- 米表层含蛋白质、脂肪、矿物质
- 精米去除杂味来源
- 心白（shinpaku）含纯淀粉

#### 洗米、浸渍
- 洗去米糠
- 吸水至最佳含水率
- 时间精确至秒

#### 蒸米 Steaming
- 蒸至外硬内软
- 适合麹菌繁殖与糖化
- 通常蒸汽30-60分钟

### 2. 麹制作 Koji Making
- **菌种**：Aspergillus oryzae（黄麹菌）
- 蒸米撒上麹菌孢子
- 控温30-40°C，湿度高
- 培养40-50小时
- 麹菌分泌酶：
  - **α-淀粉酶**：液化淀粉
  - **葡萄糖淀粉酶**：糖化为葡萄糖
  - **蛋白酶**：分解蛋白为氨基酸

### 3. 酵母酒母 Shubo（Moto）
- **目的**：培养大量健康酵母
- **原料**：米、麹、水、酵母
- 乳酸抑制杂菌
- **方法**：
  - **生酛 Kimoto**：传统自然乳酸，棍棒捣碎
  - **山废 Yamahai**：不捣碎，自然乳酸
  - **速酿系 Sokujō**：添加人工乳酸

### 4. 醪发酵 Moromi
- 三段添加 Sandan Shikomi
  - 第1天：初添（hatsuzoe）
  - 第2天：踊（odori）休息
  - 第3天：仲添（nakazoe）
  - 第4天：留添（tomezoe）
- 总量：米+麹+水逐步增加
- **并行复发酵**：
  - 麹糖化淀粉→葡萄糖
  - 酵母发酵葡萄糖→酒精
  - 同时进行
- 温度：低控温（8-15°C）
- 周期：18-32天
- 终酒精度：18-20%

### 5. 压榨、过滤
- 压榨分离酒液与酒粕
- 袋榨或自动压榨
- 过滤澄清
- 粗过滤 vs 微过滤

### 6. 巴氏杀菌 Hiire
- **第一次**：压榨后60-65°C（火入）
- **第二次**：装瓶前
- 杀菌酶与微生物
- 生酒 Namazake：未杀菌

### 7. 陈年储藏
- 0-10°C低温
- 通常6-12个月
- 古酒 Koshu：长期陈年

### 8. 装瓶前调整
- **加水**：稀释至15-16% ABV
- **原酒 Genshu**：不加水
- **火入**：第二次巴氏杀菌

## 清酒等级体系

### 精米步合 + 是否添加酿造酒精

| 等级 | 精米步合 | 酿造酒精 | 特点 |
|------|----------|----------|------|
| 纯米大吟酿 | ≤50% | 无 | 果香极致 |
| 大吟酿 | ≤50% | 少量 | 果香精致 |
| 纯米吟酿 | ≤60% | 无 | 果香饱满 |
| 吟酿 | ≤60% | 少量 | 果香优雅 |
| 特别纯米 | ≤60%或特别工艺 | 无 | 米香浓郁 |
| 特别本酿造 | ≤70%或特别工艺 | 少量 | 平衡 |
| 纯米 | ≤70% | 无 | 传统风格 |
| 本酿造 | ≤70% | 少量 | 经济款 |
| 普通酒 | - | 可加 | 日常 |

## 吟酿香 Ginjo-ka
- **香气来源**：酯类化合物
- **己酸乙酯**：苹果、菠萝
- **乙酸异戊酯**：香蕉
- 低温发酵产生
- 麹菌也贡献

## 关键变量
- **水**：硬度（硬水→「雄酒」，软水→「 feminina」）
- **酵母**：协会酵母7号、9号、1801号等
- **温度**：低温发酵保留香气
- **精米度**：决定纯净度
