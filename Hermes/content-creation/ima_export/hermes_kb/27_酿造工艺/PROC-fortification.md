# 加强酒工艺

**Fortified Wine Production**

## 概述

通过添加中性酒精终止发酵或加强酒精度，造就波特、雪利、马德拉、味美思等加强酒世界。

## 加强酒定义

### 核心工艺
- **发酵中或发酵后添加中性酒精**
- 通常使用96%葡萄酒精（aguardente）
- 提高最终酒精度至17-22%
- 保留残糖或保持干型

## 加强时机与风格

### 1. 发酵中加强（甜型）
- 中断发酵保留残糖
- 代表：波特、自然甜酒VDN
- 残糖高，酒精度高

### 2. 发酵完成后加强（干型）
- 完全发酵后加酒精
- 代表：雪利、马德拉干型
- 残糖低，酒精度高

### 3. 加强后再处理
- 调配、陈年、甜化
- 代表：味美思、奶油雪利

## 主要加强酒类型

### 波特 Port
- **产区**：葡萄牙杜罗河谷
- **工艺**：
  1. 葡萄破碎发酵至5-7°ABV
  2. 加入77%葡萄酒精（aguardente）
  3. 比例约1:4（酒精:酒液）
  4. 终酒精度19-22%
  5. 残糖约100g/L
- **风格分类**：
  - Ruby：年轻果味
  - Tawny：氧化陈年
  - Vintage：年份波特（顶尖）
  - LBV：晚装瓶年份
  - White：白波特

### 雪利 Sherry
- **产区**：西班牙赫雷斯Jerez
- **工艺**：
  1. 完全发酵至11-12%
  2. 加强至15-17%
  3. 进入Solera系统
  4. flor酵母好氧 vs 氧化
- **风格分类**：
  - Fino：flor覆盖，干型清淡
  - Manzanilla：沿海Fino
  - Oloroso：无flor，氧化浓郁
  - Amontillado：先flor后氧化
  - Pedro Ximénez（PX）：甜型
  - Cream Sherry：调配甜化

### 马德拉 Madeira
- **产区**：葡萄牙马德拉岛
- **工艺**：
  1. 完全或部分发酵
  2. 加强
  3. **estufagem加热陈年**
     - Cuba de calor：罐内加热90°C 90天
     - Canteiro：仓库自然加热数年
  4. 长期陈年
- **品种与甜度**：
  - Sercial：干型
  - Verdelho：半干
  - Bual：半甜
  - Malvasia (Malmsey)：甜型

### 味美思 Vermouth
- **工艺**：
  1. 基酒（中性葡萄酒）
  2. 加强
  3. 浸提草本、香料
  4. 调甜
- **风格**：
  - Italian / Sweet：红，甜
  - French / Dry：白，干
  - Bianco：白，半甜

### VDN（Vin Doux Naturel）
- **产区**：法国南部
- **工艺**：发酵中加酒精中止
- **代表**：
  - Muscat de Beaumes-de-Venise
  - Maury、Banyuls（Grenache）

## Solera系统

### 原理
- **梯度陈年系统**
- 多层桶（criaderas）叠加
- 最底层为Solera（最终装瓶层）
- 定期从上层向下层转移部分酒液

### 操作
1. 从Solera层取出部分装瓶
2. 同量从上一criadera补充
3. 逐层补充至最顶
4. 加入新酒至最顶

### 优势
- 风格一致稳定
- 老酒带新酒
- 复杂度高
- 持续生产

## 陈年风格

### 还原型（无氧化）
- Fino、Manzanilla
- flor酵母覆盖隔绝氧气
- 浅黄、清淡

### 氧化型
- Oloroso、Tawny、马德拉
- 主动接触氧气
- 深棕、浓郁

## 经济学
- 加强酒成本高于静止酒
- 酒精本身成本
- 长期陈年仓储成本
- Solera系统维持成本
- 传统市场萎缩，新兴市场兴起

## 现代消费
- 餐前 aperitif：味美思、Fino
- 餐后 digestif：波特、PX、马德拉
- 烹饪：马德拉、味美思
- 鸡尾酒：味美思（马天尼、Negroni）
