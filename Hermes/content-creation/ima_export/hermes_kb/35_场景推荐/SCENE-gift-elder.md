# 送长辈用酒

**Wine Gift for Elders**

## 概述

送长辈用酒推荐：兼顾健康认知、品牌认知度与礼盒包装。

## 送长辈用酒推荐

### 送长辈用酒原则

| 原则 | 说明 |
|------|------|
| 红酒为主 | 养生认知（白藜芦醇） |
| 品牌认知度 | 长辈知道、听说过 |
| 包装精美 | 礼盒、木盒 |
| 避免过高度数 | 13%以下为宜 |

### 按预算推荐

#### 经济方案（200-500元）
- 智利赤霞珠（Concha y Toro、Montes）
- 阿根廷马尔贝克（Trapiche）
- 西班牙 Rioja Reserva
- 国产精品（贺兰山、张裕）
- 配：简易礼盒

#### 中端方案（500-1500元）
- 波尔多产区级或中级庄
- 勃艮第村庄级
- 新西兰长相思（Cloudy Bay）
- 国产高端（长城五星、张裕爱斐堡）
- 配：木盒或皮盒

#### 高端方案（1500元以上）
- 波尔多列级庄（Lafite、Margaux、Mouton）
- 勃艮第一级园
- 知名香槟（Moët、Veuve Clicquot）
- 配：精致木盒 + 酒杯套装

### 按长辈偏好推荐

#### 喜欢红酒的长辈
- 波尔多红酒：经典稳重
- 勃艮第黑皮诺：优雅柔和
- 智利赤霞珠：果香易饮
- 价格：500-2000元

#### 喜欢白酒的长辈
- 勃艮第霞多丽：经典
- 新西兰长相思：清爽
- 德国雷司令：甜润易饮
- 价格：300-1500元

#### 喜欢甜酒的长辈
- 苏玳贵腐甜白：经典
- 冰酒：甜润舒缓
- Moscato d'Asti：低酒精
- 价格：300-1500元

#### 喜欢加强酒的长辈
- Tawny Port：陈年香醇
- Vintage Port：厚重醇香
- 雪利 Oloroso：复杂风味
- 价格：500-2000元

### 按节日推荐

#### 生日
- 红酒+生日蛋糕
- 知名品牌+礼盒
- 推荐：波尔多列级庄
- 预算：500-3000元

#### 春节
- 红酒+年货礼盒
- 喜庆包装
- 推荐：拉菲、玛歌
- 预算：1000-5000元

#### 中秋
- 红酒+月饼礼盒
- 甜酒配月饼
- 推荐：苏玳、Tawny Port
- 预算：500-2000元

#### 父亲节/母亲节
- 红酒+健康礼盒
- 知名品牌+心意卡
- 推荐：勃艮第、波尔多
- 预算：500-2000元

### 送长辈用酒注意事项

- 选择红酒为主（养生认知）
- 避免过高度数（13%以下）
- 附品鉴卡或健康说明
- 礼盒包装更显心意
- 提前 2 周购买（避免缺货）

### 送长辈用酒禁忌

- 避免过于小众的酒款
- 避免差年份的知名酒庄
- 避免假冒"假洋品牌"
- 避免过高度数（>14%）
