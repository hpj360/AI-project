## 储存通用原则

### 温度
| 酒类 | 最佳温度 |
|------|----------|
| 红葡萄酒 | 12-15°C |
| 白葡萄酒 | 10-13°C |
| 起泡酒 | 10-13°C |
| 甜酒 | 10-13°C |
| 加强酒 | 12-15°C |
| 烈酒 | 15-20°C |
| 清酒 | 0-5°C |
| 啤酒（陈年） | 10-13°C |

### 其他通用要求
- **湿度**：70-80%（软木塞酒）
- **避光**：所有酒类
- **平放**：软木塞封口
- **直立**：烈酒、皇冠盖啤酒
- **静置**：避免震动
- **温度恒定**：避免波动

## 适饮窗口判断

### 通用规律
1. **装瓶初期**：封闭期（1-3年）
2. **开放期**：开始展现（3-8年）
3. **巅峰期**：最佳饮用（8-30年）
4. **衰退期**：逐渐退化

### 加速老化因素
- 高温储存
- 光照
- 温度波动
- 震动
- 低湿度（软木塞干缩）

### 延长陈年因素
- 低温恒定
- 避光
- 适当湿度
- 平放（软木塞）
- 静置
