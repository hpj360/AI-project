# Pegu Club

**Pegu Club**

## 概述

Pegu Club是一款鸡尾酒，使用5种配料调制，盛于鸡尾酒杯。

## 基本信息

- **酒精度**：约 7.8% ABV（估算）
- **分类**：Cocktail
- **含酒精**：Alcoholic
- **推荐杯具**：鸡尾酒杯（Cocktail glass）

## 配方

| 配料 | 用量 |
|------|------|
| Gin | 1 1/2 oz |
| Orange Curacao | 3/4 oz |
| Lime Juice | 3/4 oz |
| Angostura Bitters | 1 dash |
| Orange Bitters | 1 dash |

## 调制方法

Shake, strain, up, cocktail glass
