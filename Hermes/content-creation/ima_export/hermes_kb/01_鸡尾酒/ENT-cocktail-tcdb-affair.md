# Affair

**Affair**

## 概述

Affair是一款经典饮品，使用4种配料调制，盛于高球杯。

## 基本信息

- **酒精度**：约 18% ABV（估算）
- **分类**：Ordinary Drink
- **含酒精**：Alcoholic
- **推荐杯具**：高球杯（Highball glass）

## 配方

| 配料 | 用量 |
|------|------|
| Strawberry schnapps | 2 oz |
| Orange juice | 2 oz |
| Cranberry juice | 2 oz |
| Club soda | 适量 |

## 调制方法

Pour schnapps, orange juice, and cranberry juice over ice in a highball glass. Top with club soda and serve.
