# Old Fashioned 古典鸡尾酒（威士忌）

**Old Fashioned**

## 概述

Old Fashioned 是 IBA The Unforgettables 系列鸡尾酒，波本/黑麦威士忌 + 糖 + 苦精，是古典杯的命名来源。

## IBA 官方配方

| 配料 | 用量 |
|------|------|
| Bourbon or Rye Whiskey | 45 ml |
| Sugar Cube（方糖） | 1 块 |
| Angostura Bitters | 数滴 |
| Plain Water | 数滴 |

- **调制法**：将方糖放入古典杯，用苦精浸透，加数滴水，捣碎至溶解；加冰块与威士忌，轻搅
- **装饰**：橙片或橙皮，鸡尾酒樱桃
