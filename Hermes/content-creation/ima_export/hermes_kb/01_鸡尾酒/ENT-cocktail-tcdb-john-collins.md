# John Collins

**John Collins**

## 概述

John Collins是一款经典饮品，使用6种配料调制，盛于柯林斯杯。

## 基本信息

- **酒精度**：约 9.8% ABV（估算）
- **分类**：Ordinary Drink
- **含酒精**：Alcoholic
- **推荐杯具**：柯林斯杯（Collins glass）

## 配方

| 配料 | 用量 |
|------|------|
| Bourbon | 2 oz |
| Lemon juice | 1 oz |
| Sugar | 1 tsp superfine |
| Club soda | 3 oz |
| Maraschino cherry | 1 |
| Orange | 1 |

## 调制方法

Pour all ingredients directly into highball glass filled with ice. Stir gently. Garnish. Add a dash of Angostura bitters.
