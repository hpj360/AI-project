# 亡者复甦（Corpse Reviver）

**Corpse Reviver**

## 概述

Corpse Reviver是一款鸡尾酒，使用5种配料调制，盛于鸡尾酒杯。

## 基本信息

- **酒精度**：约 17.8% ABV（估算）
- **分类**：Cocktail
- **含酒精**：Alcoholic
- **推荐杯具**：鸡尾酒杯（Cocktail glass）

## 配方

| 配料 | 用量 |
|------|------|
| Gin | 3/4 oz |
| Triple Sec | 3/4 oz |
| Lillet Blanc | 3/4 oz |
| Lemon Juice | 3/4 oz |
| Absinthe | 1 dash |

## 调制方法

Shake, strain, straight up, cocktail glass rinsed with absinthe
