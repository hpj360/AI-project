# Pink Penocha

**Pink Penocha**

## 概述

Pink Penocha是一款派对宾治，使用5种配料调制，盛于宾治盆。

## 基本信息

- **酒精度**：约 16.2% ABV（估算）
- **分类**：Punch / Party Drink
- **含酒精**：Alcoholic
- **推荐杯具**：宾治盆（Punch bowl）

## 配方

| 配料 | 用量 |
|------|------|
| Everclear | 750 ml |
| Vodka | 1750 ml |
| Peach schnapps | 1750 ml |
| Orange juice | 1 gal |
| Cranberry juice | 1 gal |

## 调制方法

mix all ingredients into bowl keep iced stir frequently
