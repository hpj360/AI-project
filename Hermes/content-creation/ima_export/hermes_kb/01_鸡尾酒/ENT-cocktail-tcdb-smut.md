# Smut

**Smut**

## 概述

Smut是一款派对宾治，使用4种配料调制，盛于啤酒杯。

## 基本信息

- **酒精度**：约 18% ABV（估算）
- **分类**：Punch / Party Drink
- **含酒精**：Alcoholic
- **推荐杯具**：啤酒杯（Beer mug）

## 配方

| 配料 | 用量 |
|------|------|
| Red wine | 1/3 part |
| Peach schnapps | 1 shot |
| Pepsi Cola | 1/3 part |
| Orange juice | 1/3 part |

## 调制方法

Throw it all together and serve real cold.
