# Rum Punch

**Rum Punch**

## 概述

Rum Punch是一款派对宾治，使用5种配料调制，盛于宾治盆。

## 基本信息

- **酒精度**：约 26.7% ABV（估算）
- **分类**：Punch / Party Drink
- **含酒精**：Alcoholic
- **推荐杯具**：宾治盆（Punch bowl）

## 配方

| 配料 | 用量 |
|------|------|
| Rum | mikey bottle |
| Ginger ale | large bottle |
| Fruit punch | 355 ml frozen |
| Orange juice | 355 ml frozen |
| Ice | crushed |

## 调制方法

Mix all ingredients in a punch bowl and serve.
