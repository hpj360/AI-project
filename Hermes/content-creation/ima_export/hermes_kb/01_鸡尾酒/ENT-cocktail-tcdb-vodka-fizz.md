# Vodka Fizz

**Vodka Fizz**

## 概述

Vodka Fizz是一款其他，使用5种配料调制，盛于White wine glass。

## 基本信息

- **酒精度**：约 13.3% ABV（估算）
- **分类**：Other / Unknown
- **含酒精**：Alcoholic
- **推荐杯具**：White wine glass（White wine glass）

## 配方

| 配料 | 用量 |
|------|------|
| Vodka | 2 oz |
| Half-and-half | 2 oz |
| Limeade | 2 oz |
| Ice | 适量 |
| Nutmeg | 适量 |

## 调制方法

Blend all ingredients, save nutmeg. Pour into large white wine glass and sprinkle nutmeg on top.
