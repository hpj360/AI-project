# 雪花（Snowday）

**Snowday**

## 概述

Snowday是一款鸡尾酒，使用6种配料调制，盛于柯林斯杯。

## 基本信息

- **酒精度**：约 9.4% ABV（估算）
- **分类**：Cocktail
- **含酒精**：Alcoholic
- **推荐杯具**：柯林斯杯（Collins glass）

## 配方

| 配料 | 用量 |
|------|------|
| Vodka | 1 oz |
| Amaro Montenegro | 1 oz |
| Ruby Port | 1 oz |
| Blood Orange | 1 tsp |
| Angostura Bitters | Dash |
| Orange Peel | Garnish with |

## 调制方法

Stir all ingredients with ice. Strain into a chilled rocks glass over fresh ice. Express orange peel over drink and garnish.
