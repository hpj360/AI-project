# Diesel（啤酒）

**Diesel**

## 概述

Diesel是一款啤酒鸡尾酒，使用3种配料调制，盛于品脱杯。

## 基本信息

- **酒精度**：约 18% ABV（估算）
- **分类**：Beer
- **含酒精**：Alcoholic
- **推荐杯具**：品脱杯（Pint glass）

## 配方

| 配料 | 用量 |
|------|------|
| Lager | 1/2 pint |
| Cider | 1/2 pint |
| Blackcurrant cordial | 1 dash |

## 调制方法

Pour the lager first then add the blackcurrant cordial. Top up with the cider. The colour sholud be very dark approaching the colour of Guiness.
