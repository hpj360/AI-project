# 长岛冰茶（Radioactive Long Island Iced Tea）

**Radioactive Long Island Iced Tea**

## 概述

Radioactive Long Island Iced Tea是一款经典饮品，使用8种配料调制，盛于柯林斯杯。

## 基本信息

- **酒精度**：约 28.8% ABV（估算）
- **分类**：Ordinary Drink
- **含酒精**：Alcoholic
- **推荐杯具**：柯林斯杯（Collins Glass）

## 配方

| 配料 | 用量 |
|------|------|
| Rum | 1 oz |
| Vodka | 1 oz |
| Tequila | 1 oz |
| Gin | 1 oz |
| Triple sec | 1 oz |
| Chambord raspberry liqueur | 1 oz |
| Midori melon liqueur | 1 oz |
| Malibu rum | 1 oz |

## 调制方法

Pour all ingredients over ice in a very tall glass. Sip cautiously.
