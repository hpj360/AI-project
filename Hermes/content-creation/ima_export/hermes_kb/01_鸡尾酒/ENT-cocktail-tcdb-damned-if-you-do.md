# Damned if you do

**Damned if you do**

## 概述

Damned if you do是一款烈酒shot，使用2种配料调制，盛于烈酒杯。

## 基本信息

- **酒精度**：约 30.0% ABV（估算）
- **分类**：Shot
- **含酒精**：Alcoholic
- **推荐杯具**：烈酒杯（Shot glass）

## 配方

| 配料 | 用量 |
|------|------|
| Whiskey | 0.75 oz |
| Hot Damn | 0.25 oz |

## 调制方法

Pour into shot glass. Put in mouth. Repeat as deemed necessary.
