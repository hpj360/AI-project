# Moranguito

**Moranguito**

## 概述

Moranguito是一款烈酒shot，使用3种配料调制，盛于烈酒杯。

## 基本信息

- **酒精度**：约 40.0% ABV（估算）
- **分类**：Shot
- **含酒精**：Alcoholic
- **推荐杯具**：烈酒杯（Shot glass）

## 配方

| 配料 | 用量 |
|------|------|
| Absinthe | 2/5 |
| Tequila | 2/5 |
| Grenadine | 1/5 |

## 调制方法

first you put rhe absinthe, then put tequila, then put the Granadine syrup.
