# Rum Runner

**Rum Runner**

## 概述

Rum Runner是一款派对宾治，使用5种配料调制，盛于鸡尾酒杯。

## 基本信息

- **酒精度**：约 8.0% ABV（估算）
- **分类**：Punch / Party Drink
- **含酒精**：Alcoholic
- **推荐杯具**：鸡尾酒杯（Cocktail glass）

## 配方

| 配料 | 用量 |
|------|------|
| Malibu rum | 1 1/2 oz |
| Blackberry brandy | 1 oz |
| Orange juice | 3-4 oz |
| Pineapple juice | 3-4 oz |
| Cranberry juice | 3-4 oz |

## 调制方法

Mix all ingredients in glass & add ice.
