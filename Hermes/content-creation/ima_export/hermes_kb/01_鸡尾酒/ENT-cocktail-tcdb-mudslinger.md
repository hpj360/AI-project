# Mudslinger

**Mudslinger**

## 概述

Mudslinger是一款派对宾治，使用3种配料调制，盛于宾治盆。

## 基本信息

- **酒精度**：约 18% ABV（估算）
- **分类**：Punch / Party Drink
- **含酒精**：Alcoholic
- **推荐杯具**：宾治盆（Punch bowl）

## 配方

| 配料 | 用量 |
|------|------|
| Southern Comfort | 750 ml |
| Orange juice | 1 L |
| Pepsi Cola | 750 ml |

## 调制方法

Add all contents to a large jug or punch bowl. Stir well!
