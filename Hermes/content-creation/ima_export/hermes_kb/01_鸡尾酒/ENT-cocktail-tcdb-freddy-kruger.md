# 库克（Freddy Kruger）

**Freddy Kruger**

## 概述

Freddy Kruger是一款烈酒shot，使用3种配料调制，盛于烈酒杯。

## 基本信息

- **酒精度**：约 13.3% ABV（估算）
- **分类**：Shot
- **含酒精**：Alcoholic
- **推荐杯具**：烈酒杯（Shot glass）

## 配方

| 配料 | 用量 |
|------|------|
| Jägermeister | 1/2 oz |
| Sambuca | 1/2 oz |
| Vodka | 1/2 oz |

make it an ample size shot!!
