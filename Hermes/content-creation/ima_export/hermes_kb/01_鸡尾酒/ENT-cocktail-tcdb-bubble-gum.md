# Bubble Gum

**Bubble Gum**

## 概述

Bubble Gum是一款烈酒shot，使用4种配料调制，盛于烈酒杯。

## 基本信息

- **酒精度**：约 10.0% ABV（估算）
- **分类**：Shot
- **含酒精**：Alcoholic
- **推荐杯具**：烈酒杯（Shot glass）

## 配方

| 配料 | 用量 |
|------|------|
| Vodka | 1/4 |
| Banana liqueur | 1/4 |
| Orange juice | 1/4 |
| Peach schnapps | 1/4 |

## 调制方法

Layer in order into a shot glass.
