# 断塞/坏塞处理

**Cork Failure Handling SOP**

## 概述

断塞、坏塞、TCA 污染的应急处理规范。

## 断塞/坏塞处理规范

### 常见问题分类

| 问题 | 描述 | 处理难度 |
|------|------|----------|
| 断塞 | 软木塞断裂在瓶内 | 中 |
| 半断塞 | 拔塞时塞子裂开 | 中 |
| 老塞脆弱 | 老酒软木塞易碎 | 高 |
| 液面渗漏 | 酒塞渗漏 | 低 |
| TCA 污染 | 软木塞异味 | 高 |

### 断塞处理流程

#### 情况1：塞子断在瓶口

1. **保持冷静**
   - 不要慌张
   - 向客人致歉并说明

2. **重新插入螺旋锥**
   - 将螺旋锥以 45 度角插入剩余塞子
   - 注意不要穿透
   - 缓慢旋入

3. **缓慢拔出**
   - 利用海马刀杠杆
   - 缓慢撬起
   - 配合手轻拔

4. **失败处理**
   - 改用 Ah-So 老酒开瓶器
   - 或用长螺丝+扳手拔出
   - 必要时用推入法

#### 情况2：塞子掉入瓶中

1. **告知客人**
   - 说明情况
   - 询问是否继续

2. **过滤服务**
   - 用醒酒器换瓶
   - 用纱布或滤网过滤
   - 服务澄清酒液

3. **快速消费**
   - 建议尽快饮用
   - 不宜长时间保存

### 老塞脆弱处理

#### 提前预防
- 老酒提前 24 小时直立静置
- 使用 Ah-So 老酒开瓶器
- 双片金属片夹住塞子

#### 操作要点
1. 将金属片沿塞子两侧插入
2. 一前一后，缓慢摇动
3. 夹住塞子后缓慢旋转拔出
4. 避免用力过猛

### TCA 污染处理

#### TCA 识别
- 闻起来：湿纸板、霉味、潮湿地下室
- 口感：果香消失、平淡
- 来源：软木塞三氯苯甲醚

#### 处理流程

1. **试饮时识别**
   - 点酒人试饮时发现
   - 或侍酒师察觉

2. **告知客人**
   - 礼貌说明情况
   - 不是酒庄品质问题

3. **更换酒款**
   - 立即换新瓶
   - 同款或同价位替代
   - 重新试饮流程

4. **后续处理**
   - 记录 TCA 案例
   - 联系供应商
   - 整批检测（如多次出现）

### 渗漏处理

#### 识别
- 瓶帽有酒渍
- 软木塞湿润凸起
- 液面下降

#### 处理
- 检查酒质（是否氧化）
- 短期可饮用
- 长期储存风险高
- 重要酒款建议立即饮用

### 应急工具

| 工具 | 用途 |
|------|------|
| Ah-So 开瓶器 | 老酒脆弱塞 |
| 长螺丝+扳手 | 断塞应急 |
| 滤网/纱布 | 塞子掉入 |
| 备用酒款 | TCA 更换 |
| 醒酒器 | 换瓶过滤 |

### 注意事项

- 断塞时不丢脸，专业处理是关键
- TCA 是天然问题，不需客人买单
- 老酒开瓶建议提前准备
- 服务态度比技术更重要
