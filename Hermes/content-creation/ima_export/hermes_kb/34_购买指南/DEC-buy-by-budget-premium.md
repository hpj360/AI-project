# 2000元以上高端选酒

**Premium Wine Buying Guide Above 2000 RMB**

## 概述

2000元以上的高端选酒策略：触达顶级名庄、特级园与传奇年份。

## 2000元以上高端选酒策略

### 选购原则

| 原则 | 说明 |
|------|------|
| 顶级名庄 | 一级庄、DRC、Pétrus 等 |
| 传奇年份 | 1982、2000、2005、2009、2010 等 |
| 完整溯源 | 进口商、酒窖记录、二级市场 |
| 专业仓储 | 恒温恒湿、避光避震 |

### 推荐酒款

#### 红葡萄酒
- 波尔多一级庄：Lafite、Latour、Margaux、Haut-Brion、Mouton
- 右岸顶级：Pétrus、Le Pin、Cheval Blanc、Ausone
- 勃艮第：DRC（Romanée-Conti、La Tâche）、Leroy、Roumier
- 意大利：Sassicaia、Ornellaia、Masseto
- 西班牙：Vega Sicilia Único Reserva Especial
- 美国：Screaming Eagle、Harlan Estate、Opus One
- 澳洲：Penfolds Grange（新年份）

#### 白葡萄酒
- 勃艮第：DRC Montrachet、Coche-Dury Meursault
- 德国：Egon Müller Scharzhofberger TBA
- 法国：Château d'Yquem（标准装）

#### 甜酒与加强酒
- 苏玳：Château d'Yquem（大年份）
- 托卡伊：Essencia
- 波特：Vintage Port（陈年）

### 购买渠道

- 正规进口商：富隆、桃乐丝、ASC
- 拍卖行：苏富比、佳士得、Zachys
- 二级市场：Cult Wines、Vinfolio
- 酒庄直采：列级庄期酒

### 风险提示

- 假酒风险高，必须验证溯源
- 关注酒塞状态、液面高度
- 长期储存需专业酒窖
