# 年份选择指南

**Vintage Selection Guide**

## 概述

年份选择策略：伟大年份、平价年份、入门年份的差异与选择。

## 年份选择指南

### 年份的重要性

- 年份指葡萄采摘年份
- 反映当年气候与葡萄品质
- 影响陈年潜力与市场价格

### 波尔多伟大年份

| 年份 | 评价 | 陈年潜力 |
|------|------|----------|
| 1982 | 传奇年份 | 50年+ |
| 2000 | 经典年份 | 30-50年 |
| 2005 | 卓越年份 | 30-50年 |
| 2009 | 丰厚年份 | 25-40年 |
| 2010 | 经典结构 | 30-50年 |
| 2015 | 优雅年份 | 20-30年 |
| 2016 | 卓越年份 | 30-50年 |
| 2019 | 优秀年份 | 20-30年 |

### 勃艮第伟大年份

- 红葡萄酒：1990、2005、2009、2010、2015、2018
- 白葡萄酒：2014、2017、2019

### 平价年份（性价比高）

- 波尔多：2008、2011、2012、2014
- 勃艮第：2011、2014
- 特征：品质良好、价格合理、可早饮

### 差年份（建议避开）

- 波尔多：1991、1992、1997、2013
- 特征：雨水多、成熟度不足
- 注意：名庄在差年份仍有保障

### 新世界年份差异

| 产区 | 特征 |
|------|------|
| 智利 | 年份差异较小，气候稳定 |
| 阿根廷 | 年份差异较小 |
| 澳大利亚 | 部分年份有极端气候 |
| 新西兰 | 较稳定，关注产区 |
| 南非 | 部分年份较热 |

### 选择建议

#### 收藏与投资
- 选伟大年份、顶级名庄
- 关注酒评家评分 95+

#### 商务宴请
- 选良好年份（2005、2010、2015、2016）
- 知名酒庄的中端产品

#### 日常饮用
- 选平价年份或新世界
- 关注即饮型酒款

#### 红白差异
- 白葡萄酒：选新年份（保持果香）
- 红葡萄酒：陈年可选老年份
- 甜酒：老年份增值潜力大

### 年份查询工具

- Wine Advocate、Wine Spectator
- 各产区行业协会官网
- CellarTracker 社区评分
