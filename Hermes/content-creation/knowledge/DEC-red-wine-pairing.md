# 红酒配餐决策树

## 概述

根据菜品类型选择红酒的系统化决策流程。

## 决策流程

### 第 1 步：判断菜品主料
- 红肉（牛/羊/鹿）→ 高单宁红酒
- 白肉（鸡/猪/鸭）→ 中等单宁红酒
- 海鲜 → 低单宁或白葡萄酒
- 甜点 → 甜型葡萄酒

### 第 2 步：判断烹饪方式
- 烤/煎 → 浓郁型红酒（赤霞珠/西拉）
- 炖/煮 → 柔和型红酒（黑皮诺/梅洛）
- 生食/清淡 → 清爽型（桃红/干白）

### 第 3 步：判断酱汁
- 浓酱（黑椒/红酒汁）→ 浓郁红酒
- 清淡酱 → 中等酒体
- 辣酱 → 略甜型/低单宁

### 第 4 步：预算与场合
- 日常（<150 元）：智利赤霞珠、阿根廷马尔贝克
- 进阶（150-500 元）：法国波尔多、意大利基安蒂
- 收藏（>500 元）：勃艮第特级园、纳帕谷名庄

### 推荐搭配
- 牛排 → 赤霞珠、马尔贝克
- 烤鸭 → 黑皮诺、梅洛
- 炖牛肉 → 西拉、仙粉黛
- 羊排 → 赤霞珠、波尔多混酿
- 烤鸡 → 黑皮诺、品丽珠
- 番茄意面 → 基安蒂、巴贝拉
