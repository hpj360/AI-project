# 白葡萄酒配餐决策树

## 概述

根据菜品风味选择白葡萄酒的系统化决策流程。

## 决策流程

### 第 1 步：判断食材类型
- 海鲜（生蚝/贝类）→ 高酸干白
- 白肉（鸡/火鸡）→ 中等酒体干白
- 鱼类（三文鱼/金枪鱼）→ 饱满干白或轻盈红酒
- 沙拉/前菜 → 清爽干白
- 甜点 → 甜白

### 第 2 步：判断烹饪方式
- 生食/清蒸 → 高酸轻盈（长相思、夏布利）
- 烤/煎 → 过桶霞多丽、维欧尼
- 奶油酱 → 饱满干白（过桶霞多丽）
- 番茄酱 → 高酸干白（灰皮诺）

### 第 3 步：判断风味强度
- 清淡菜 → 长相思、灰皮诺、夏布利
- 中等菜 → 雷司令干、白皮诺
- 浓郁菜 → 过桶霞多丽、维欧尼

### 第 4 步：考虑地域搭配
- 法式海鲜 → 夏布利、密斯卡岱
- 意式海鲜 → 灰皮诺、维尔纳恰
- 日式刺身 → 吟酿酒、长相思
- 泰式酸辣 → 雷司令半干、琼瑶浆

### 推荐搭配
- 生蚝 → 夏布利、密斯卡岱
- 三文鱼 → 过桶霞多丽、黑皮诺
- 龙虾 → 过桶霞多丽
- 鸡肉沙拉 → 长相思
- 寿司 → 雷司令干、吟酿
- 泰式料理 → 琼瑶浆、雷司令半甜
- 蓝纹奶酪 → 苏玳贵腐
