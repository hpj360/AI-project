# 送客户用酒

**Wine Gift for Clients**

## 概述

送客户用酒推荐：兼顾品牌认知度、品质稳定与商务礼仪。

## 送客户用酒推荐

### 送客户用酒原则

| 原则 | 说明 |
|------|------|
| 品牌认知度 | 客户知道、听说过 |
| 品质稳定 | 大年份、知名酒庄 |
| 包装精美 | 木盒、皮盒、礼盒 |
| 附赠品鉴卡 | 体现专业与用心 |

### 按客户偏好推荐

#### 喜欢红酒的客户
- 波尔多列级庄：经典稳重
- 勃艮第特级园：稀有珍贵
- 意大利 Super Tuscan：独特品味
- 价格：1000-10000元

#### 喜欢白酒的客户
- 勃艮第特级园干白：顶级
- 德国顶级雷司令：稀有
- 阿尔萨斯特级园：独特
- 价格：1000-5000元

#### 喜欢香槟的客户
- 年份香槟：经典选择
- 顶级特酿 Cuvée de Prestige：高端
- 知名品牌（Krug、Salon、Bollinger）
- 价格：1500-5000元

#### 喜欢甜酒的客户
- 苏玳 Château d'Yquem：顶级
- 托卡伊 Essencia：稀有
- 冰酒：甜润珍贵
- 价格：1000-10000元

### 按节日推荐

#### 春节
- 红酒+礼盒+年货
- 知名品牌+喜庆包装
- 推荐：拉菲、玛歌、木桐
- 预算：1500-10000元

#### 中秋
- 红酒+月饼礼盒
- 知名品牌+精致包装
- 推荐：波尔多列级庄
- 预算：1000-5000元

#### 圣诞/新年
- 香槟+礼盒
- 年份香槟+贺卡
- 推荐：Krug、Salon、Vintage
- 预算：1500-5000元

#### 签约庆功
- 香槟+礼盒
- 顶级香槟+贺卡
- 推荐：年份香槟、顶级特酿
- 预算：2000-8000元

### 送客户用酒注意事项

- 选择知名品牌（客户认知度）
- 附品鉴卡或酒庄介绍
- 礼盒包装+手提袋
- 提前 2 周购买（避免缺货）
- 保留购买凭证（售后保障）

### 送客户用酒禁忌

- 避免过于小众的酒款
- 避免差年份的知名酒庄
- 避免假冒"假洋品牌"
- 避免过高度数
- 避免与客户偏好冲突
