# 混酒饮用风险

## 概述

混合饮用不同酒类易加重醉酒与不适，需谨慎搭配。

## 风险机制

### 1. 酒精总量失控
- 不同酒类口感差异大
- 难以感知累计酒精量
- 容易过量

### 2. 杂醇油叠加
- 不同酒类含不同杂醇油
- 混饮后杂醇油总量增加
- 加重宿醉（头痛、恶心）

### 3. 不同酒精度刺激
- 高低度数交替刺激胃
- 加重肝脏负担
- 加速酒精吸收

### 4. 碳酸 + 烈酒特别危险
- 碳酸饮料加速胃排空
- 烈酒快速进入小肠
- 血液酒精浓度急升
- 例：威士忌兑可乐、伏特加兑苏打

## 常见误区
- 「酒混着喝更醉」→ 部分对，主要是总量失控
- 「先白后啤没事」→ 错，啤酒碳酸加速酒精吸收
- 「洋酒混果汁没事」→ 风险仍在
- 「喝红酒再喝白酒没事」→ 错，杂醇叠加

## 高风险组合

### 1. 烈酒 + 碳酸饮料
- 例：威士忌 + 可乐、伏特加 + 苏打
- 风险：碳酸加速吸收
- 易醉酒、易宿醉

### 2. 啤酒 + 烈酒
- 「深水炸弹」等
- 啤酒碳酸 + 烈酒高度数
- 极易醉倒

### 3. 不同香型白酒混饮
- 酱香 + 浓香 + 清香
- 杂醇油叠加
- 宿醉严重

### 4. 葡萄酒 + 烈酒
- 风格差异大
- 难以把控总量

## 安全建议

### 推荐做法
- 一场聚会只饮一种酒类
- 若必须混饮：先低度后高度（避免反向）
- 控制总酒精量
- 多喝水、多进食

### 不推荐
- 啤酒 + 白酒（最危险组合之一）
- 红酒 + 白酒（杂醇叠加）
- 多种鸡尾酒混合（隐藏高度数）
- 含咖啡因饮料 + 酒精（掩盖醉意）

### 宿醉缓解
- 多喝水
- 电解质补充（运动饮料、椰子水）
- 蜂蜜水（果糖代谢）
- 充足睡眠
- 维生素 B 族
- 不再「以酒解酒」
