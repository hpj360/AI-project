# 服药期间饮酒禁忌

## 概述

服用头孢类、甲硝唑、降糖药等药物期间饮酒可引发严重反应，甚至危及生命。

## 双硫仑样反应（最危险）

### 致命药物组合
- **头孢类抗生素**（头孢曲松、头孢哌酮等）
- **甲硝唑、替硝唑**（抗厌氧菌）
- **呋喃唑酮、氯霉素**
- 磺胺类

### 反应症状
- 面部潮红、头痛
- 心悸、胸闷
- 恶心呕吐
- 血压下降
- 休克、死亡

### 原理
- 药物抑制乙醛脱氢酶
- 乙醛在体内蓄积中毒
- 用药期间及停药后 7-14 天内禁酒

## 其他药物禁忌

### 降糖药
- 双胍类（二甲双胍）+ 酒精 → 乳酸酸中毒
- 磺脲类 + 酒精 → 严重低血糖

### 镇静催眠药
- 苯二氮卓类（安定）+ 酒精 → 中枢抑制、呼吸抑制
- 巴比妥类 + 酒精 → 致死风险

### 解热镇痛药
- 对乙酰氨基酚（扑热息痛）+ 酒精 → 肝损伤
- 阿司匹林、布洛芬 + 酒精 → 胃出血

### 抗抑郁药
- SSRI + 酒精 → 增强中枢抑制
- 三环类 + 酒精 → 心血管风险

### 抗凝药
- 华法林 + 酒精 → 出血风险或药效改变

### 心血管药
- 降压药 + 酒精 → 严重低血压
- 硝酸甘油 + 酒精 → 致命低血压

## 用药建议
- 服药期间一律禁酒
- 停药后至少 7 天再饮酒（头孢类需 14 天）
- 中药也需咨询医生（部分含酒精或相互作用）
- 服用任何处方药前阅读说明书
