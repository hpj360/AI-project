# 威士忌酒杯选择

## 概述

威士忌酒杯选择：格兰凯恩杯、闻香杯、古典杯的用途差异。

## 主要威士忌杯型

### 1. 格兰凯恩杯（Glencairn）
- 特征：郁金香形、收口、厚底
- 用途：专业品鉴、闻香
- 优势：聚拢香气，是威士忌行业标杆
- 容量：约 175ml，倒酒 20-30ml

### 2. 闻香杯（Copita / Norlan）
- 特征：长茎、小杯肚、收口
- 用途：深度闻香、品鉴会
- 优势：香气集中度高，适合单一麦芽

### 3. 古典杯（Old Fashioned / Rocks）
- 特征：矮身、宽口、厚壁
- 用途：加冰饮用、调酒
- 优势：容纳冰块，耐用
- 适合：日常饮用、加冰块

### 4. ISO 标准杯
- 用途：专业品鉴、横向对比
- 优势：标准统一，无偏向

### 5. Norlan 双层杯
- 特征：双层壁设计
- 用途：纯饮，聚香同时美观
- 优势：现代设计，手感佳

## 选择原则

### 纯饮 / 闻香
- 优选：格兰凯恩杯、闻香杯
- 原因：聚香，方便摇杯

### 加冰饮用
- 优选：古典杯
- 原因：容纳大冰块，厚壁抗温差

### 混饮 / Highball
- 优选：Highball 杯（直身长杯）
- 原因：容纳碳酸饮料

### 品鉴会
- 优选：ISO 杯或格兰凯恩杯
- 原因：标准化对比

## 倒酒量参考
- 纯饮：20-30ml
- 加冰：30-45ml + 大冰块
- Highball：45ml 威士忌 + 苏打水补满
