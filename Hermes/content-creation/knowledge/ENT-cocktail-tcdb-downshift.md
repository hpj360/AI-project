# Downshift

**Downshift**

## 概述

Downshift是一款派对宾治，使用4种配料调制，盛于飓风杯。

## 基本信息

- **酒精度**：约 22.2% ABV（估算）
- **分类**：Punch / Party Drink
- **含酒精**：Alcoholic
- **推荐杯具**：飓风杯（Hurricane glass）

## 配方

| 配料 | 用量 |
|------|------|
| Fruit punch | 2 part |
| Sprite | 1 part |
| Tequila | 2 shots |
| 151 proof rum | Float Bacardi |

## 调制方法

Start with the Sprite. Next comes the tequila. After that, add the Minute Maid Fruit Punch, then float the 151. Rocks optional.
