# 白葡萄酒品鉴法

## 概述

白葡萄酒专业品鉴流程，重点关注酸度、芳香与温度。

## 品鉴步骤

### 1. 观色
- 杯中酒量约 1/3，白色背景前观察
- 颜色：青绿（年轻）→ 稻草黄（成熟）→ 金黄（陈年/橡木）
- 透明度通常高于红酒，雾浊可能为缺陷

### 2. 闻香
- 冷酒香气较内敛，先轻闻再摇杯
- 一类香气：柑橘、青苹果、梨、热带水果
- 二类香气：橡木带来的黄油、香草、烤面包（过桶款）
- 三类香气：陈年的蜂蜜、坚果、 petrol（雷司令陈年标志）

### 3. 品味
- 重点评估酸度（白葡萄酒的灵魂）
- 酒体：轻盈（长相思）→ 中等（霞多丽未过桶）→ 饱满（过桶霞多丽）
- 甜度：干型 / 半干 / 半甜 / 甜型

### 4. 回味
- 干白通常回味较短，优质酒余味中的果香与矿物感持久

### 5. 适饮温度
- 轻盈干白：7-10℃
- 饱满干白：10-13℃
- 甜白：6-8℃
