# Daiquiri 戴基丽

**Daiquiri**

## 概述

Daiquiri 是 IBA The Unforgettables 系列鸡尾酒，白朗姆 + 青柠汁 + 糖，源自古巴。

## IBA 官方配方

| 配料 | 用量 |
|------|------|
| White Rum | 45 ml |
| Lime or Lemon Juice | 20 ml |
| Sugar | 1 茶匙 |

- **调制法**：Shake（摇和），滤入 short drink 杯
