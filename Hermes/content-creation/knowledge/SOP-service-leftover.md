# 剩酒保存方法

**Leftover Wine Storage Methods**

## 概述

剩酒保存方法：抽真空、惰性气体、冷藏等专业保存技巧。

## 剩酒保存方法

### 剩酒氧化原理

- 开瓶后酒液接触空气
- 氧化反应使酒质下降
- 果香逐渐消失
- 口感变平淡

### 保存时间参考

| 酒款类型 | 冰箱保存 | 真空保存 | 惰性气体 |
|----------|----------|----------|----------|
| 轻酒体干白 | 1-2 天 | 2-3 天 | 3-5 天 |
| 重酒体干白 | 2-3 天 | 3-4 天 | 5-7 天 |
| 轻酒体红酒 | 2-3 天 | 3-4 天 | 5-7 天 |
| 重酒体红酒 | 3-4 天 | 4-5 天 | 7-10 天 |
| 甜酒 | 5-7 天 | 7-10 天 | 10-14 天 |
| 加强酒 | 7-14 天 | 14-21 天 | 21-30 天 |
| 起泡酒 | 1 天 | 1-2 天 | 不适用 |

### 保存方法详解

#### 1. 抽真空保存

| 工具 | 说明 |
|------|------|
| 抽真空泵 | 手动或电动 |
| 真空塞 | 配套橡胶塞 |

**操作流程**
1. 将真空塞插入瓶口
2. 用抽真空泵抽气
3. 听到"咔嗒"声表示完成
4. 直立存放冰箱

**优点**
- 价格便宜
- 操作简单
- 适用于大部分酒款

**缺点**
- 无法完全真空
- 不适用于起泡酒
- 风味仍会缓慢变化

#### 2. 惰性气体保存

**操作流程**
1. 将惰性气体喷入瓶中
2. 气体（氩气或氮气）下沉覆盖酒液
3. 迅速塞回原塞
4. 直立存放冰箱

**优点**
- 隔氧效果最佳
- 保存时间最长
- 适用于贵重酒款

**缺点**
- 成本较高
- 气体需定期补充
- 罐装携带不便

#### 3. 冰箱冷藏

**操作流程**
1. 重新塞回原软木塞
2. 直立存放冰箱
3. 温度 4-8℃
4. 饮用前提前取出

**优点**
- 简单方便
- 无需额外工具
- 短期保存适用

**缺点**
- 仍会缓慢氧化
- 冰箱异味可能渗入
- 红酒饮用前需回温

#### 4. 起泡酒保存

**专用工具**
- 起泡酒专用塞（带卡扣）
- 可承受瓶内压力

**操作流程**
1. 立即用专用塞密封
2. 卡扣固定
3. 冰箱冷藏
4. 24 小时内饮用

#### 5. 小瓶分装

**操作流程**
1. 准备小容量瓶（375ml、187ml）
2. 将剩酒倒入小瓶
3. 减少空气接触面积
4. 密封冷藏

**优点**
- 减少氧化面积
- 适用于不同酒款
- 操作简单

### 不建议的保存

| 做法 | 问题 |
|------|------|
| 室温放置 | 快速氧化 |
| 横放 | 增加接触面积 |
| 重新加热 | 破坏酒质 |
| 长期冷冻 | 破坏酒质 |

### 剩酒再利用

#### 烹饪
- 红酒炖牛肉
- 红酒酱汁
- 白酒海鲜烹饪

#### 调酒
- Sangria 桑格利亚
- 红酒热饮 Mulled Wine

#### 制醋
- 红酒醋
- 白酒醋

### 实用建议

- 剩酒及时保存，不要拖延
- 贵重酒款建议惰性气体
- 起泡酒尽快饮用
- 加强酒保存时间最长
