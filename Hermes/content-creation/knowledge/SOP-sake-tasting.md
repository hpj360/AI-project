# 清酒品鉴法

## 概述

清酒品鉴需结合温度与酒器，重点评估甘辛、香气与余韵。

## 品鉴步骤

### 1. 选定温度
- 冷酒（5-15℃）：突出果香与清爽感，适合吟酿酒
- 常温（20℃左右）：平衡展现，适合纯米酒
- 燗酒（40-55℃）：突出米香与醇厚，适合本酿造/纯米

### 2. 选定酒器
- 猪口杯（小瓷杯）：传统，适合燗酒
- 白瓷杯：便于观察酒色
- 葡萄酒杯：聚香，适合吟酿、大吟酿
- 木质杯（桧木）：增添木香，搭配特定酒款

### 3. 观色
- 透明 / 微黄（陈酒或有陈化）
- 浊酒（浊り酒）为正常现象

### 4. 闻香
- 吟酿香：果香、花香（苹果、香蕉、甜瓜）
- 纯米系：米糠、乳酸、坚果
- 熟成酒：焦糖、坚果、酱油般醇香

### 5. 品味
- 甘辛度：甘口 / 中口 / 辛口
- 酸度：清爽型 / 圆润型
- 余韵：吟酿系短而清；纯米系长而厚

### 6. 温度变化
- 同一瓶酒在不同温度下呈现完全不同风味
- 建议冷饮→常温→燗酒逐次体验
