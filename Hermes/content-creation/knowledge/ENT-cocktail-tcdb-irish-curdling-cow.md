# Irish Curdling Cow

**Irish Curdling Cow**

## 概述

Irish Curdling Cow是一款鸡尾酒，使用4种配料调制，盛于高球杯。

## 基本信息

- **酒精度**：约 25.9% ABV（估算）
- **分类**：Cocktail
- **含酒精**：Alcoholic
- **推荐杯具**：高球杯（Highball glass）

## 配方

| 配料 | 用量 |
|------|------|
| Baileys irish cream | 3/4 oz |
| Bourbon | 3/4 oz |
| Vodka | 3/4 oz |
| Orange juice | 2-3 oz |

## 调制方法

Pour Irish Cream, Vodka, and Bourbon in a glass. Add some ice and mix in the orange juice.
