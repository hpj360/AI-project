# 波尔多杯选择与使用

**Bordeaux Glass Selection**

## 概述

波尔多杯的设计原理、适用品种及正确使用方法。

## 杯型设计

### 设计原理

- **高杯身**：25-30cm，让酒液有足够空间舒展
- **宽腹收口**：杯腹宽大增加氧化面积，收口聚拢香气
- **大容量**：600-750ml，倒酒不超过1/3
- **杯肚比例**：略高于宽，适合单宁重的酒款

### 适用品种

- 赤霞珠（Cabernet Sauvignon）
- 美乐（Merlot）
- 西拉（Syrah/Shiraz）
- 波尔多混酿

### 使用方法

1. **持杯**：握杯柄或杯底，避免手温影响酒温
2. **倒酒**：倒入杯腹最宽处，约1/3容量
3. **摇杯**：顺时针轻摇，释放香气
4. **品鉴**：先闻香，再小口品尝
