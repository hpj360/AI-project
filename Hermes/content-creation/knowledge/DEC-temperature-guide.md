# 适饮温度决策

## 概述

根据酒类、季节、场合确定适饮温度的决策流程。

## 决策流程

### 第 1 步：按酒类确定基础温度

| 酒类 | 温度范围 |
|-----|---------|
| 起泡酒/香槟 | 6-10℃ |
| 甜白葡萄酒 | 6-8℃ |
| 轻盈干白 | 7-10℃ |
| 饱满干白 | 10-13℃ |
| 桃红葡萄酒 | 8-12℃ |
| 轻盈红酒 | 13-15℃ |
| 中等红酒 | 15-18℃ |
| 浓郁红酒 | 16-18℃ |
| 甜型加强酒 | 14-18℃ |
| 干型加强酒 |6-10℃ |
| 威士忌纯饮 | 室温（18-20℃）|
| 清酒冷饮 | 5-15℃ |
| 清酒燗酒 | 40-55℃ |
| 白酒 | 15-25℃ |
| 啤酒（拉格） | 3-5℃ |
| 啤酒（艾尔） | 8-13℃ |

### 第 2 步：季节调整
- **夏季**：白葡萄酒/啤酒取下限，红酒略低（15-16℃）
- **冬季**：红酒取上限（18℃），白葡萄酒不必太冰
- 春秋：标准温度

### 第 3 步：场合调整
- 户外聚餐：温度略低（防止快速升温）
- 室内正式：严格按标准
- 派对：白葡萄酒/啤酒取下限（保持清爽）
- 品鉴会：精确控温

### 第 4 步：温度异常的影响

#### 过冷
- 红酒：香气封闭、单宁更显涩
- 白酒：香气被锁住
- 啤酒：风味平淡

#### 过热
- 红酒：酒精感突出、香气散失
- 白酒：酸度突兀、失衡
- 啤酒：泡沫过盛、口感松散

### 第 5 步：降温/升温方法

#### 降温
- 冰水桶：15-20 分钟（最快）
- 冰箱冷藏：2-3 小时
- 冷冻室：紧急 15-20 分钟（注意勿忘）
- 不推荐：加冰块（稀释酒液，仅啤酒/烈酒可用）

#### 升温
- 手掌捂杯（红酒微调）
- 温水浴（清酒燗酒）
- 室温静置

### 实用速查
- 红酒刚从酒柜（14℃）取出 → 直接饮用（标准）
- 夏季红酒需稍冰镇 15 分钟
- 白葡萄酒从冰箱取出后 10 分钟内饮用
- 香槟倒酒后 30 分钟内饮完（防升温）
