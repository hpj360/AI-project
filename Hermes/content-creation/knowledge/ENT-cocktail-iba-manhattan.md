# Manhattan 曼哈顿

**Manhattan**

## 概述

Manhattan 是 IBA The Unforgettables 系列鸡尾酒，黑麦威士忌 + 甜味美思 + 安古斯图拉苦精。

## IBA 官方配方

| 配料 | 用量 |
|------|------|
| Rye Whiskey（黑麦威士忌） | 50 ml |
| Sweet Red Vermouth | 20 ml |
| Angostura Bitters | 1 滴 |

- **调制法**：Mixing glass 搅拌，滤入 short drink 杯
- **装饰**：樱桃
- **威士忌**：可用美国或加拿大威士忌
