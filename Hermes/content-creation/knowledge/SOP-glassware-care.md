# 酒具清洁与保养

**Glassware Care and Maintenance**

## 概述

酒具的水洗vs机洗、水晶杯护理、存放规范等清洁保养知识。

## 清洁方法

### 手洗规范

1. **温水清洗**：40-50℃温水，避免热水
2. **无香洗剂**：使用无香精洗洁精，避免残留
3. **柔软海绵**：用软海绵或专用杯刷
4. **冲洗彻底**：清水冲洗至无泡沫残留
5. **擦干技巧**：用无绒棉布擦干，避免水痕

### 机洗规范

| 项目 | 建议 |
|------|------|
| 水温 | ≤55℃ |
| 洗剂 | 无香无磷 |
| 摆放 | 杯口朝下、避免碰撞 |
| 程序 | 玻璃器皿程序 |
| 干燥 | 自然晾干 |

### 不同材质护理

#### 水晶杯（含铅24%+）

- **禁机洗**：高温易导致雾化
- **手洗温度**：≤45℃
- **擦拭**：超细纤维布
- **存放**：直立放置，避免杯口接触

#### 无铅水晶杯

- **可机洗**：使用玻璃程序
- **耐受性**：较好，不易雾化
- **擦布**：棉质或超细纤维
- **使用寿命**：5-10年

#### 普通玻璃杯

- **可机洗**：标准程序
- **抗摔性**：较好
- **保养**：简单冲洗即可
- **更换周期**：根据磨损程度

## 常见问题处理

### 雾化（Cloudiness）

| 原因 | 处理方法 |
|------|---------|
| 硬水沉积 | 白醋浸泡30分钟 |
| 高温烘干 | 改用自然晾干 |
| 洗剂残留 | 重新清水冲洗 |
| 老化磨损 | 无法恢复，需更换 |

### 水痕（Water Spots）

1. **及时擦干**：清洗后立即擦拭
2. **蒸馏水冲洗**：最后用蒸馏水过一遍
3. **蒸汽擦干**：用蒸汽处理后擦干
4. **专用擦布**：超细纤维布效果最佳

### 异味残留

- **小苏打浸泡**：温水+2勺小苏打，浸泡1小时
- **柠檬汁清洗**：去味杀菌
- **阳光晾晒**：通风处晾干
- **活性炭**：存放时放活性炭吸味

## 存放规范

### 杯具存放

| 存放方式 | 优点 | 缺点 |
|---------|------|------|
| 杯口朝上 | 不接触柜体灰尘 | 易积灰尘 |
| 杯口朝下 | 防尘 | 杯口易磨损 |
| 悬挂倒挂 | 通风、防尘 | 占用空间 |
| 专用杯架 | 隔离保护 | 成本高 |

### 推荐存放

1. **杯柄朝下**：杯口朝上，避免杯口接触柜体
2. **隔板垫**：软木或绒布垫隔板
3. **避免堆叠**：水晶杯禁止堆叠
4. **通风干燥**：存放处通风良好
5. **远离热源**：避免阳光直射和热源

### 醒酒器存放

1. **倒置晾干**：彻底干燥后存放
2. **专用支架**：避免滚动碰撞
3. **软布包裹**：长期存放用软布包裹
4. **避免挤压**：单独存放空间

### 开瓶器保养

| 类型 | 保养方法 |
|------|---------|
| 海马刀 | 螺旋钻擦干、铰链滴油 |
| 电动开瓶器 | 充电存放、避免潮湿 |
| 老酒开瓶器 | 金属片擦干、防锈 |
| 香槟刀 | 刀刃防锈、布袋包裹 |
