# 配餐基本原则

## 概述

酒类配餐基本原则：红酒红肉、白酒白肉、甜酒甜点的传统原则与进阶方法。

## 传统配餐三原则

### 1. 红酒配红肉
- 原理：红酒单宁与蛋白质结合，软化单宁、提升肉香
- 经典：赤霞珠 + 牛排、西拉 + 烤羊
- 例外：轻盈黑皮诺也可配三文鱼

### 2. 白酒配白肉
- 原理：白酒酸度解腻、衬托白肉鲜味
- 经典：霞多丽 + 鸡肉、长相思 + 海鲜
- 例外：过桶霞多丽可配烤猪排

### 3. 甜酒配甜点
- 原理：酒甜度需 ≥ 食物甜度，否则酒变酸
- 经典：苏玳 + 水果塔、波特 + 巧克力
- 例外：贵腐 + 蓝纹奶酪（咸甜对比）

## 进阶配餐方法

### 浓度匹配
- 浓味菜 → 浓郁酒
- 清淡菜 → 清爽酒
- 例：红烧肉 → 浓郁红酒；清蒸鱼 → 干白

### 酸度匹配
- 菜肴酸度 ≤ 酒的酸度
- 番茄、柠檬菜需高酸酒
- 油脂丰富菜需高酸解腻

### 甜度匹配
- 酒甜度 ≥ 菜甜度
- 辣菜可搭配略甜酒（解辣）

### 风味互补 vs 风味对比
- 互补：奶油酱 + 过桶霞多丽（奶油风味）
- 对比：蓝纹奶酪 + 贵腐甜酒（咸甜反差）

## 特殊配餐原则

### 中餐配酒
- 川菜：起泡酒、雷司令（解辣）
- 粤菜：干白、轻盈红酒
- 鲁菜：饱满红酒
- 江浙菜：半干白

### 辣菜配酒
- 忌：高单宁、高酒精度（加重辣感）
- 宜：略甜、低酒精度、起泡
- 推荐：莫斯卡托、雷司令半甜

### 各酒类经典搭配
- 生蚝 + 夏布利
- 牛排 + 赤霞珠
- 鹅肝 + 苏玳贵腐
- 寿司 + 吟酿清酒
- 烧烤 + 波本威士忌
- 火锅 + 清爽拉格啤酒
