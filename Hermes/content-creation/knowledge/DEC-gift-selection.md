# 送酒决策树

## 概述

根据送礼对象、预算、收礼人偏好选择酒类的决策流程。

## 决策流程

### 第 1 步：送礼对象
- 长辈 → 白酒（茅台/五粮液）、陈年威士忌
- 客户/商务 → 茅台飞天、五粮液、麦卡伦 18 年
- 朋友 → 按其偏好，威士忌/红酒/精酿
- 女性 → 甜型葡萄酒、起泡酒、莫斯卡托
- 同事 → 红酒、起泡酒（百元级）
- 节日家宴 → 红酒、白酒组合

### 第 2 步：预算
- <200 元：精酿啤酒礼盒、入门红酒、本酿造清酒
- 200-500 元：中端红酒、水晶剑、洋河天之蓝、调和威士忌
- 500-1000 元：茅台王子/汉酱、五粮液系列、单一麦芽 12 年
- 1000-3000 元：茅台飞天、五粮液普五、麦卡伦 18 年、勃艮第名庄
- >3000 元：茅台年份酒、麦卡伦 25 年、顶级名庄红酒、限量威士忌

### 第 3 步：收礼人偏好
- 已知偏好 → 直接选其偏好品牌
- 未知偏好 → 硬通货（茅台、五粮液、麦卡伦）
- 喜爱尝鲜 → 小众产区、独立装瓶威士忌
- 注重健康 → 低度酒、有机葡萄酒

### 第 4 步：场合
- 婚庆 → 红酒、起泡酒（寓意好）
- 寿宴 → 白酒（茅台、五粮液）
- 升迁 → 香槟、威士忌
- 节日（春节）→ 白酒、红酒
- 探病 → 不送酒（送营养品）

### 第 5 步：包装与象征
- 红色包装：喜庆场合
- 木盒/礼盒：高端正式
- 生肖版/年份版：收藏价值
- 完整原箱：保值增值

### 硬通货推荐
- 中国：茅台飞天、五粮液普五
- 威士忌：麦卡伦 18 年、响 21 年
- 红酒：拉菲、木桐（顶级）/ 智利蒙特斯（中端）
- 香槟：酩悦、库克
