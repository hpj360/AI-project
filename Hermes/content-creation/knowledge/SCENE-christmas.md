# 圣诞节用酒

**Christmas Wine**

## 概述

圣诞节用酒推荐：传统节日饮品、圣诞大餐配酒全套指南。

## 圣诞节用酒推荐

### 圣诞用酒原则

| 原则 | 说明 |
|------|------|
| 传统饮品 | 热红酒、蛋奶酒 |
| 节日氛围 | 香槟庆祝 |
| 大餐搭配 | 火鸡、鹅肉配酒 |
| 分享为主 | 适合多人聚会 |

### 圣诞传统饮品

#### 1. 热红酒 Mulled Wine

| 配方 | 用量 |
|------|------|
| 红酒 | 1 瓶（750ml） |
| 橙子 | 1 个（切片） |
| 肉桂棒 | 2 根 |
| 丁香 | 8-10 粒 |
| 八角 | 2-3 粒 |
| 蜂蜜或糖 | 50-100g |
| 白兰地（可选） | 50ml |

**制作方法**
1. 红酒倒入锅中
2. 加入所有香料和水果
3. 小火加热至 70-80℃（不要沸腾）
4. 加入蜂蜜调味
5. 过滤后趁热饮用

#### 2. 蛋奶酒 Eggnog
- 牛奶 + 奶油 + 蛋 + 糖
- 加入波本或朗姆酒
- 撒肉豆蔻粉
- 冷饮或热饮

#### 3. 热苹果酒
- 苹果汁 + 肉桂 + 丁香
- 可加朗姆酒
- 热饮暖身

- 甜酒：苏玳顶级、Vintage Port

### 圣诞用酒注意事项

- 提前准备热红酒原料
- 香槟充分冰镇
- 红酒适当醒酒
- 准备多种酒杯
- 注意酒精度（老人、孩子）

### 圣诞用酒禁忌

- 避免过高度数
- 避免与甜品冲突
- 避免差年份的酒款
- 避免过于小众的酒
